# Sahil Khan — Portfolio

A modern, animated personal portfolio website for **Sahil Khan**, a Fullstack Developer based in Mumbai, India. Built with a bold, minimal design language, smooth motion, and an interactive loading experience.

## ✨ Overview

This portfolio showcases Sahil's work, technical skills, and contact information through a single-page, scroll-driven experience with heavy use of typography, animation, and marquee-style text.

---

## 🖥️ Sections

1. **Loading Screen**
   - A minimal intro animation displaying "Hii, नमस्ते, ..." (Namaste) on a black background before transitioning into the site.

2. **Hero Section**
   - Large bold headline: _"Crafting Modern & Digital Experiences"_
   - Personal photo, availability status ("Open for offers and collaborations"), and location tag ("Mumbai — Ind").

3. **About / Intro**
   - Scrolling marquee text: _"FULLSTACK DEVELOPER"_
   - Short bio: _"I build fast, interactive and scalable web experiences that combine thoughtful design, smooth animations and clean code — creating products that people enjoy using and businesses can rely on."_

4. **Selected Works**
   - A horizontally scrollable project showcase featuring:
     - ThinkGestalt Tech
     - ThinkGestalt Design
     - ThinkGestalt Media
     - Social (additional project)

5. **Technologies**
   - Grid of tools and technologies used, including:
     - React, Next.js, TypeScript, JavaScript
     - Tailwind CSS, GSAP, Framer Motion, Node.js
     - Express.js, MongoDB, Git, Figma

6. **Contact / Footer**
   - Call-to-action: _"Let's Build Something."_
   - Buttons: **Book a Call** and **Drop us an Email**
   - Social links: LinkedIn, Instagram, Twitter
   - Large stylized signature-style name display ("SAHIL").

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Sahilk9211/sahil-portfolio-vol1.git

# Navigate into the project
cd your-repo

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.
